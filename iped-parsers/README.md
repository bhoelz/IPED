# iped-parsers

Parent of all artifact parsers (~31 submodules): Tika extensions and forensic-specific parsers (registry, lnk, usnjrnl, browsers, P2P apps, mail, sqlite family, mobile chat apps, etc.), plus `iped-parsers-common`/`-main`/`-impl` aggregation.
