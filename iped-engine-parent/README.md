# iped-engine-parent

Aggregator for the engine split: the historical monolithic `iped-engine` broken into focused submodules (`iped-engine-core`, `iped-engine`, `iped-engine-graph`, `iped-engine-hashdb`, `iped-sleuthkit`, `iped-ufed`, `iped-ad1`, `iped-distributed`, `iped-additional-index`) with enforced dependency boundaries between them. Each submodule has its own roadmap; this module's roadmap tracks the cross-cutting plan.

## Roadmap

See [iped-engine-parent-ROADMAP.md](../docs/roadmaps/iped-engine-parent-ROADMAP.md) for the cross-cutting plan, and each submodule's own `README.md` for its specific roadmap.
