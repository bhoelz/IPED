# Core

- `api`: client gerado e contratos de integração com `iped-webapi`.
- `config`: configuração de ambiente e constantes transversais.
- `http`: interceptors, tratamento de erro e utilitários de transporte.

Regras:
- código gerado não deve ser editado manualmente;
- integrações transversais não devem depender de componentes de tela.
