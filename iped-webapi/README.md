# iped-webapi

Jersey/JAX-RS REST API on embedded Jetty exposing case open/search/item/viewer capabilities of the engine (`iped.engine.webapi`, JSON models incl. `v2`). The single backend contract for `iped-webui`, `iped-webui-server`, and `iped-mcp`.
