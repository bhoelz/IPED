# ISSUE-226: Generate a per-parser documentation page into the API docs set

- Status: planned
- Roadmap: [iped-parsers-ROADMAP.md](../roadmaps/iped-parsers-ROADMAP.md)
- Roadmap section: Phase 4 — 5.0
- Owner: unassigned
- Created: 2026-06-21
- Updated: 2026-06-21

## Summary

Each parser should get a generated documentation page describing what it extracts
and which properties it emits, folded into the scripting/API documentation set.

## Problem

There is currently no per-parser documentation describing extracted data and emitted
properties, making it harder for scripting/API users to discover parser behavior.

## Acceptance criteria

- [ ] Define the documentation format/generation mechanism for per-parser pages.
- [ ] Generate pages covering what each parser extracts and which properties it
      emits.
- [ ] Integrate generated pages into the scripting/API documentation set.
