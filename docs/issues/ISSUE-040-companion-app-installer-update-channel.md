## Summary

Build the distribution mechanics for the companion app: an installer, code signing, and an update channel, so analysts can install and keep the companion app current.

## Problem

The companion app currently has no defined installer, signing, or update mechanism, which blocks it from being distributed to analysts as a standalone artifact.

## Acceptance criteria

- [ ] Installer produced for the companion app.
- [ ] Signing pipeline in place for the companion app artifacts.
- [ ] Update channel defined so installed companion apps can be kept current.
