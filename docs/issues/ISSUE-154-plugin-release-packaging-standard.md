## Summary

Padronizar o formato de release de plugin (JAR + assinatura + checksum + SBOM) e criar um guia de publicação para mantenedores de plugins de terceiros.

## Problem

Sem um formato de release padronizado, cada publisher de plugin poderia empacotar artefatos de forma inconsistente, dificultando a verificação automatizada e a auditoria de proveniência (SBOM).

## Acceptance criteria

- [ ] Definir o formato padrão de release: JAR + assinatura + checksum SHA-256 + SBOM.
- [ ] Documentar o guia de publicação para mantenedores de plugins.
